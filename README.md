# Mental Math Game

A Tkinter arithmetic practice game that generates questions, checks answers, tracks response time, and shows a session summary. The newer source version also saves a high score in JSON.

## Features in `mainv2.py`

- Random addition, subtraction, multiplication, and division questions.
- Keyboard answer entry with immediate feedback.
- Session totals, accuracy, total/average response time, and a performance score.
- A persistent high score in `results.json`.

## Requirements and setup

Python 3 with Tkinter. Run `python mainv2.py` from the `mental_math` project directory so the image and JSON paths resolve.

## Limitations

The current app uses relative paths and accepts floating-point text for answers. Session scoring and edge cases need review before calling it complete. Drive file metadata lists the selected source as created and modified 2026-09-13; no authored project date appears in the source.
