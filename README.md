# Mental Math Game

**Project date: 13 September 2026.**

A Tkinter arithmetic practice game that generates questions, checks answers, tracks response time, and shows a session summary. The game also saves a high score in JSON.

## Features

- Random addition, subtraction, multiplication, and division questions.
- Keyboard answer entry with immediate feedback.
- Session totals, accuracy, response time, and performance score.
- A persistent high score in `results.json`.

## Requirements and setup

Python 3 with Tkinter. Run `python main.py` from the project directory so image and JSON paths resolve.

## Limitations

The app uses relative paths and accepts floating-point text for answers. Session scoring and edge cases could use further work.
